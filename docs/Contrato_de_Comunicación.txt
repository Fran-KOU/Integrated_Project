### Tabla 1: Contrato de comunicación del grupo

| Tema | Acuerdo |
| :--- | :--- |
| **Canales** | WhatsApp para coordinación rápida, GitHub y Go para tareas de código, y Discord para reuniones. |
| **Reuniones** | Dos reuniones semanales de 2 horas los días miércoles y viernes desde las 6:00 pm, y una verificación antes de cada entrega. |
| **Tiempo de respuesta** | Urgencias: 30 minutos, temas normales: 1 hora y, sin respuesta en 6 horas, la reunión se mueve al siguiente día. |
| **Toma de decisiones** | Se debate el tema y, en caso de desacuerdo, se vota y la opción con la mayoría gana. |
| **Manejo de conflictos** | - Hablar directamente con la persona.<br>- Llevarlo a la reunión semanal en Discord con hechos. |
| **Cumplimiento de tareas** | Cada tarea tiene como responsable al grupo entero; asimismo, el cumplimiento de su fecha límite es responsabilidad de todo el grupo. |
| **Evidencia de aporte** | Cada integrante trabaja con commits propios; los avances se verifican en el historial de Git. |
